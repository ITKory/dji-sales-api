# Sales Performance

## Запуск одной командой

Из корня проекта, при запущенном Docker с Docker Compose:

```sh
docker compose up --build -d --wait
```

Команда собирает фронтенд и API, запускает PostgreSQL, применяет миграции,
загружает демоданные и ждёт готовности сервисов.
Локально устанавливать Node.js и .NET для этого не требуется.

- Интерфейс: http://localhost:5173
- API / Swagger: http://localhost:5026/swagger
- Проверка готовности API: http://localhost:5026/health/ready

Фронтенд отправляет запросы на `/api` через nginx к API внутри Docker-сети.
После изменения кода повторите команду запуска, чтобы пересобрать приложение.

Настройки по умолчанию работают без `.env`. При необходимости скопируйте
`.env.example` в `.env` и измените `FRONTEND_PORT`, `API_PORT` или настройки БД.
Демоданные охватывают 24.09.2025–23.09.2026 (набор `sales-demo-v1`), поэтому за
текущий период данных может не быть — выберите диапазон внутри этого интервала.

Логи:

```sh
docker compose logs -f
```

Остановка с сохранением данных PostgreSQL:

```sh
docker compose down
```
